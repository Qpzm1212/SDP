# Assignment 2: Creational Patterns (Factory Method & Abstract Factory)

**Theme:** Mountain Bike Workshop (Мастерская по сборке горных велосипедов).

- **Part A (Factory Method):** Manages the creation and maintenance of individual bicycle components (`HydraulicBrakes`, `Suspension`, `Drivetrain`).
- **Part B (Abstract Factory):** Assembles consistent families of bike products (`Frame` + `Wheel`) for specific riding styles (`Downhill` and `Roadbike`), ensuring compatibility.
